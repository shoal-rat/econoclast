# Code of conduct

## The short version

Be decent. This is a project about holding research to a high standard, so hold each other to a high
standard of respect too. Criticise work, not people.

## Expected behaviour

- Assume good faith and give specific, actionable feedback.
- Keep discussion technical. Disagree about methods, not about identities.
- Remember the tool's own rule: a flagged result is a hypothesis to check, not an accusation. The same
  applies to how you talk to contributors.

## Unacceptable behaviour

Harassment, personal attacks, or using Econoclast's output to harass authors. Findings from this tool
must never be posted as public accusations of misconduct.

## Enforcement

Report problems to zwk@outlook.sg. Maintainers may edit, remove, or reject contributions and comments
that violate this code, and may ban repeat offenders.

This is adapted from the spirit of the [Contributor Covenant](https://www.contributor-covenant.org).
